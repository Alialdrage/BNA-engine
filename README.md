# BNA Engine V3

محرك تحليل نصوص عربي (Build • Navigate • Analyze) مبني على Next.js وTailwind CSS، ويدعم اللهجة العراقية.

## التشغيل

```bash
npm install
cp .env.example .env.local   # اختياري، لتفعيل الذكاء الاصطناعي
npm run dev
```

ثم افتح http://localhost:3000

## الإعدادات

| المتغير | الوصف |
|---|---|
| `ANTHROPIC_API_KEY` | مفتاح Claude API. عند ضبطه تعمل محركات الذكاء الاصطناعي واللغة العراقية بتحليل حقيقي. |
| `ANTHROPIC_MODEL` | اسم النموذج (الافتراضي `claude-haiku-5-5`). |
| `GEMINI_API_KEY` | مفتاح Gemini API. يفعّل محركي Gemini 4 وGemini 3.8. |
| `GEMINI4_MODEL` | معرف نموذج Gemini 4 (الافتراضي `gemini-4-argon`). |
| `GEMINI38_MODEL` | معرف نموذج Gemini 3.8 (الافتراضي `gemini-3.8-flash`). |
| `AI_RATE_LIMIT_PER_MINUTE` | عدد طلبات الذكاء الاصطناعي (Claude وGemini) لكل IP في الدقيقة (الافتراضي `10`). |

بدون المفتاح يعمل المحرك بوضع القواعد، ويعرض ملاحظة توضح ذلك.

## المحركات

| المحرك | ماذا يفعل |
|---|---|
| تلقائي | يختار المحرك المناسب للنص. |
| ذكاء اصطناعي | تحليل الموضوع والنبرة والنقاط الأساسية والمخاطر (يحتاج المفتاح). |
| لغة عراقية | يكشف مؤشرات اللهجة العراقية، ويعيد الصياغة بالفصحى (يحتاج المفتاح للتحليل الكامل). |
| Gemini 4 | نفس تحليل "ذكاء اصطناعي" لكن عبر Gemini 4 (يحتاج `GEMINI_API_KEY`). |
| Gemini 3.8 | نفس التحليل عبر Gemini 3.8 Flash، أسرع وأرخص (يحتاج `GEMINI_API_KEY`). |
| بيانات | يستخرج الأرقام والإيميلات والروابط ويحسب المجموع والمتوسط. |
| تحليلات | إحصاءات النص وأكثر الكلمات تكراراً. |
| بحث | يقترح كلمات مفتاحية وروابط بحث. |
| أتمتة | يحوّل النص إلى خطوات مرقمة. |

## الـ API

`POST /api/bna`

```json
{ "engine": "ANALYTICS", "input": "النص هنا" }
```

الرد الناجح: `{ "result": "..." }`
الرد عند الخطأ: `{ "error": "..." }` مع رمز 400 أو 502.

الحد الأقصى للنص: 20000 حرف.

عند تجاوز حد طلبات الذكاء الاصطناعي يرجع الـ API رمز `429` مع ترويسة `Retry-After`. الحد يُخزَّن في ذاكرة الخادم، لذلك يعمل على خادم واحد. للنشر على عدة خوادم استخدم Redis أو ما شابه.

## الأمان

- المفتاح يُقرأ على الخادم فقط ولا يصل إلى المتصفح.
- ملفات `.env` مستثناة من Git.
- النص المدخل يُعامل كبيانات فقط، ولا يُنفَّذ أي تعليم موجود داخله.

# BNA Engine V3

محرك تحليل نصوص عربي (Build • Navigate • Analyze) مبني على Next.js وTailwind CSS، ويدعم اللهجة العراقية.

## التشغيل

```bash
npm install
cp .env.example .env.local   # اختياري، لتفعيل الذكاء الاصطناعي
npm run dev
```

ثم افتح http://localhost:3000

## الإعدادات

| المتغير | الوصف |
|---|---|
| `ANTHROPIC_API_KEY` | مفتاح Claude API. عند ضبطه تعمل محركات الذكاء الاصطناعي واللغة العراقية بتحليل حقيقي. |
| `ANTHROPIC_MODEL` | اسم النموذج (الافتراضي `claude-haiku-5-5`). |
| `GEMINI_API_KEY` | مفتاح Gemini API. يفعّل محركي Gemini 4 وGemini 3.8. |
| `GEMINI4_MODEL` | معرف نموذج Gemini 4 (الافتراضي `gemini-4-argon`). |
| `GEMINI38_MODEL` | معرف نموذج Gemini 3.8 (الافتراضي `gemini-3.8-flash`). |
| `WEB_RATE_LIMIT_PER_HOUR` | حد البحث في الويب والبحث العميق لكل IP في الساعة (الافتراضي `20`)، لأن كل عملية بحث لها تكلفة. |
| `WEB_SEARCH_MAX_USES` / `DEEP_RESEARCH_MAX_USES` / `WRITER_SEARCH_MAX_USES` | أقصى عدد عمليات بحث في الطلب (الافتراضي `5` و`12` و`8`، الحد `30`). |
| `ANTHROPIC_BASE_URL` | عنوان بديل لواجهة Claude (بوابة أو وكيل). الافتراضي `https://api.anthropic.com`. |
| `ANTHROPIC_WEB_SEARCH_TOOL` | إصدار أداة البحث (الافتراضي `web_search_20250305`). |
| `IMAGE_RATE_LIMIT_PER_MINUTE` | عدد طلبات توليد الصور لكل IP في الدقيقة (الافتراضي `12`). |
| `AI_RATE_LIMIT_PER_MINUTE` | عدد طلبات الذكاء الاصطناعي (Claude وGemini) لكل IP في الدقيقة (الافتراضي `10`). |

بدون المفتاح يعمل المحرك بوضع القواعد، ويعرض ملاحظة توضح ذلك.

## المحركات والمهارات

**ذكاء اصطناعي** (تحتاج `ANTHROPIC_API_KEY` أو `GEMINI_API_KEY`؛ بدونهما تظهر ملاحظة توضح ذلك):

| المحرك | ماذا يفعل |
|---|---|
| تلقائي | يختار المناسب: JSON أو حساب إن كان النص كذلك، وإلا الذكاء الاصطناعي، وإلا المحركات المحلية. |
| ذكاء اصطناعي | تحليل الموضوع والنبرة والنقاط الأساسية والمخاطر. |
| لغة عراقية | يكشف اللهجة العراقية ويعيد الصياغة بالفصحى. |
| Gemini 4 / Gemini 3.8 | نفس التحليل عبر Gemini (يحتاج `GEMINI_API_KEY`). |
| ترجمة | عربي ⇄ إنجليزي (أو لغة تحددها). |
| مبرمج | كتابة الكود وشرحه وإصلاحه. |
| كاتب | تحسين النصوص وإعادة صياغتها وكتابة نصوص جديدة. |
| بحث ويب | يبحث في الويب ويجيب بمعلومات حديثة مع الاستعلامات والمصادر. عبر أداة البحث في Claude، أو Google Search في Gemini إن لم يوجد مفتاح Claude. |
| بحث عميق | يقسّم السؤال ويجري حتى 12 عملية بحث ويكتب تقريراً: ملخص، نتائج، مقارنات، تعارضات، توصيات، ثم المصادر. أبطأ وأغلى. |
| تحليل عميق | تحليل استراتيجي لموضوع أو بيانات تلصقها: افتراضات، أسباب، خيارات، سيناريوهات، توصية. بلا بحث في الويب. |
| تأليف | يؤلف نصاً أصلياً طويلاً: قصة، فصل رواية، مسرحية، قصيدة، خطبة، كتيب. للكتب يبدأ بالخطة ثم الفصل الأول، ويتابع الفصول من ذاكرة المحادثة. لا ينسخ أعمالاً منشورة. |
| بحث وكتابة | يبحث في الويب ثم يكتب مقالاً أو تقريراً أو منشوراً بالأسلوب المطلوب اعتماداً على ما وجده، مع المصادر. |
| صور | يولّد صورة من وصف (عبر خدمة Pollinations المجانية، ويمر الطلب عبر خادمك). مع مفتاح ذكاء اصطناعي يُترجم الوصف للإنجليزية أولاً لنتيجة أفضل. كلمات مثل "عمودي" أو "أفقي" تغيّر المقاس. |
| فيديو | يكتب خطة فيديو كاملة: مشاهد ومدد وتعليق صوتي ووصف لكل مشهد. **لا ينتج ملف فيديو**، فالمولّدات الفعلية تحتاج خدمات مدفوعة. |
| ألغاز | ألعاب كلامية (ألغاز، أسئلة ثقافية، عشرين سؤالاً) تستخدم ذاكرة المحادثة لحساب النقاط. |

**مهارات محلية** (تعمل بدون أي مفتاح ولا تتصل بأي خدمة):

| المهارة | ماذا تفعل |
|---|---|
| بيانات | يستخرج الأرقام والإيميلات والروابط ويحسب المجموع والمتوسط. |
| تحليلات | إحصاءات النص وأكثر الكلمات تكراراً. |
| بحث | كلمات مفتاحية وروابط بحث. |
| أتمتة | يحوّل النص إلى خطوات مرقمة. |
| تلخيص | تلخيص استخراجي بأهم الجمل. |
| مشاعر | نبرة النص (إيجابي/سلبي) بالقاموس، مع فهم النفي. |
| حاسبة | معادلات (`2+3*4`، `sqrt(16)`، أرقام عربية) وتحويل وحدات (`10 km to mi`، `100 c to f`). |
| تاريخ | ميلادي وهجري واليوم من الأسبوع والفرق بين تاريخين (`2026-01-01 2026-03-01`) أو `+30`. |
| JSON | تحقق وتنسيق وإحصاءات وموضع الخطأ. |
| ترميز | Base64 وHex وURL وSHA-256 وSHA-1 وMD5 مع فك الترميز. |
| تنظيف | حذف التشكيل والتطويل والأسطر المكررة والفارغة. |
| كلمة مرور | يولّد 5 كلمات مرور قوية بمولّد آمن (الطول من النص، 8 إلى 64). |

> **ملاحظة عن البحث في الويب:** يجب أن يكون البحث مفعّلاً لمنظمتك في [Claude Console](https://platform.claude.com/settings/capabilities)، وكل 1000 عملية بحث تُحاسب بسعر مستقل فوق تكلفة التوكنات. إن كان معطّلاً سيظهر خطأ من الخدمة.

## استوديو الكتب (تبويب 📖 الكتب)

تأليف كتاب كامل بخطوات: تكتب الفكرة (والنوع والجمهور) ← يولّد الذكاء الاصطناعي مخططاً بعدد الفصول ← يكتب الفصول بالبث (واحداً واحداً أو كلها) ← تعدّل النص بيدك وتعيد ترتيب الفصول وتحذفها أو تضيف ← تصدّر.

- **الطباعة / PDF:** غلاف، فهرس، وكل فصل في صفحة جديدة بتنسيق عربي من اليمين لليسار. اختر «حفظ كـ PDF» من نافذة الطباعة.
- **Word (.docx)** و**HTML** و**Markdown**.
- الكتاب يُحفظ في متصفحك فقط (`localStorage`)، فصدّره قبل مسح بيانات المتصفح. يحتاج مفتاح Claude أو Gemini لتوليد المخطط والفصول، أما الكتابة اليدوية والتصدير فيعملان بدونه.
- مراجعة النص قبل النشر مسؤوليتك: قد يخطئ الذكاء الاصطناعي في الوقائع.

## الألعاب

تبويب "الألعاب" يعمل كله في المتصفح بلا خادم: إكس أو ضد حاسوب (سهل أو لا يُهزم)، ولعبة الذاكرة، وخمّن الرقم، وحجر ورقة مقص.

## الواجهة

تظهر الصفحة افتراضياً بصندوق الطلب فقط، والمحرك **تلقائي** يختار المهارة المناسبة. لاختيار مهارة بنفسك اكتب `/` في الصندوق فتظهر اقتراحات (مثل `/صور قطة تلبس نظارات` أو `/translate hello`). زر «☰ الأدوات والمهارات» يعرض كل الأزرار والسلاسل وتبويبي الكتب والألعاب، وإخفاؤها يعيد الوضع التلقائي.

## دمج المهارات (سلاسل)

زر «🔗 دمج المهارات» في تبويب المحركات: اضغط على المهارات بالترتيب (حتى 5) فيصبح ناتج كل خطوة مدخلاً للتي بعدها، مثل **ابحث ← لخّص ← ترجم**. توجد سلاسل جاهزة في القائمة. قسم المصادر لا يُمرَّر للخطوة التالية، وإن فشلت خطوة تبقى نتائج الخطوات السابقة. كل خطوة ذكية تُحسب ضمن حدود الطلبات.

## الروابط الحيّة

روابط المصادر في البحث (وأي رابط http/https في الرد) تظهر قابلة للنقر وتُفتح في تبويب جديد بـ `rel="noopener noreferrer nofollow"`. أي رابط بغير http/https (مثل `javascript:`) يبقى نصاً فقط.

## البث والذاكرة

- الردود الذكية تظهر تدريجياً أثناء توليدها (بث)، ويوجد زر إيقاف.
- المحادثة تُحفظ في متصفحك فقط (`localStorage`)، وآخر 6 محادثات تُرسل للخادم كذاكرة لمحركات الذكاء الاصطناعي. مخرجات "كلمة مرور" لا تُحفظ. زر "مسح المحادثة" يحذف كل شيء.

## الـ API

`POST /api/bna`

```json
{ "engine": "ANALYTICS", "input": "النص هنا", "history": [], "stream": false }
```

- `history` (اختياري): مصفوفة `{ "role": "user" | "assistant", "content": "..." }`، آخر 12 رسالة فقط وتُقصّ وتُتحقق على الخادم.
- `stream: true`: يرجع النص تدريجياً (`text/plain`) واسم المحرك في ترويسة `X-BNA-Engine` (مرمّز URL).

الرد الناجح: `{ "result": "...", "engine": "اسم المحرك" }`
الرد عند الخطأ: `{ "error": "..." }` مع رمز 400 أو 502.

الحد الأقصى للنص: 20000 حرف.

عند تجاوز حد طلبات الذكاء الاصطناعي يرجع الـ API رمز `429` مع ترويسة `Retry-After`. الحد يُخزَّن في ذاكرة الخادم، لذلك يعمل على خادم واحد. للنشر على عدة خوادم استخدم Redis أو ما شابه.

## الأمان

- المفتاح يُقرأ على الخادم فقط ولا يصل إلى المتصفح.
- ملفات `.env` مستثناة من Git.
- النص المدخل يُعامل كبيانات فقط، ولا يُنفَّذ أي تعليم موجود داخله.

## مرفقات وأدوات وصوت

- **رؤية وملفات (`VISION`):** زر 📎 يرفق حتى 3 ملفات: صور (تُصغَّر في المتصفح إلى 1280px) وPDF (حتى 2.4MB) تُرسل إلى Claude/Gemini، وملفات نصية وكود تُضاف إلى الطلب. تحتاج `ANTHROPIC_API_KEY` أو `GEMINI_API_KEY`. Word/Excel غير مدعومة (احفظها PDF).
- **استدعاء الأدوات تلقائياً:** مع Claude يستدعي المحرك الحاسبة والتاريخ وتنسيق JSON وفحص الكتابة بنفسه (حتى 4 جولات) في محركات المحادثة والذكاء والتحليل العميق والرؤية. عطّله بـ `TOOLS=off`.
- **الصوت:** 🎤 إملاء و🔊 نطق عبر Web Speech API في المتصفح (يعمل أفضل في Chrome)، ولا يمر عبر الخادم.
